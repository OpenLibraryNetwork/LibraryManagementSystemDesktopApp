# Λίστα ελέγχου: Strapi 5 (μετάβαση)

Προετοιμασία:
- Στο `library-strapi/.env` προσθέστε `ENCRYPTION_KEY=` με τυχαία τιμή, π.χ. από `openssl rand -base64 32` (νέα ρύθμιση της Strapi 5 για το admin).
- `cd library-strapi && nvm use && npm run develop` (Node 24). Νέα βάση: δημιουργία διαχειριστή στο `/admin`.
- Η παλιά τοπική βάση του JavaFX (H2) φυλάχτηκε στο `data/backup-strapi4/`. Η εφαρμογή χρησιμοποιεί νέα βάση (μέλη και δανεισμοί από την αρχή).

## Εκκίνηση και διαχείριση
- [ ] Η Strapi ξεκινά με Node 24 χωρίς σφάλμα `NODE_MODULE_VERSION`.
- [ ] Στο admin: δημιουργία βιβλιοθήκης και χρήστη (Users & Permissions → Users) με ρόλο **Librarian** και βιβλιοθήκη.
- [ ] Δημιουργία δεύτερου χρήστη με ρόλο **Authenticated** (για τον έλεγχο σύνδεσης).
- [ ] Settings → Users & Permissions → Advanced settings: η «Enable sign-ups» είναι **κλειστή**.

## Σύνδεση JavaFX
- [ ] Το JavaFX ζητά σύνδεση (η παλιά αποθηκευμένη συνεδρία δεν ισχύει πια) και ανοίγει χωρίς σφάλμα.
- [ ] Σύνδεση με τον Authenticated χρήστη → «Ο λογαριασμός δεν είναι βιβλιοθηκονόμου…».
- [ ] Σύνδεση με τον Librarian → κανονικά.

# Λίστα ελέγχου: Κατάλογος μόνο για ανάγνωση (υπο-έργο 2α)

## Προετοιμασία

1. Strapi: `cd library-strapi && nvm use 20 && npm run develop`. Στο admin, δημιουργήστε μια Βιβλιοθήκη και έναν χρήστη
   (Content Manager → User) με ρόλο **Librarian** και αυτή τη βιβλιοθήκη.
2. JWT του librarian (αντικαταστήστε χρήστη και κωδικό):

   ```bash
   curl -s -X POST http://localhost:1337/api/auth/local -H 'Content-Type: application/json' \
     -d '{"identifier":"USER","password":"PASS"}'
   ```

   Αντιγράψτε το `jwt` της απάντησης: `export JWT=...`
3. Ρόλοι (σημειώστε τα id του «Συγγραφέας» και του «Μεταφραστής»):

   ```bash
   curl -s http://localhost:1337/api/contributor-roles -H "Authorization: Bearer $JWT"
   ```

4. Πρόσωπα, εκδότης, μπροσούρα, αντίτυπο (σημειώνετε κάθε `data.id` που επιστρέφεται):

   ```bash
   curl -s -X POST http://localhost:1337/api/persons/local -H "Authorization: Bearer $JWT" -H 'Content-Type: application/json' -d '{"data":{"name":"Νίκη Λοϊζίδη","bornYear":"1950"}}'
   curl -s -X POST http://localhost:1337/api/persons/local -H "Authorization: Bearer $JWT" -H 'Content-Type: application/json' -d '{"data":{"name":"Παναγιώτης Σκόνδρας"}}'
   curl -s -X POST http://localhost:1337/api/publishers/local -H "Authorization: Bearer $JWT" -H 'Content-Type: application/json' -d '{"data":{"name":"Εκδόσεις Γειτονιάς","address":"Αθήνα"}}'
   curl -s -X POST http://localhost:1337/api/books/local -H "Authorization: Bearer $JWT" -H 'Content-Type: application/json' -d '{"data":{"type":"Μπροσούρα","title":"Αυτοοργάνωση","yearPublished":2019,"summary":"Δοκιμαστική περίληψη.","publisher":PUBLISHER_ID,"contributors":[{"person":NIKI_ID,"role":AUTHOR_ROLE_ID},{"person":PANOS_ID,"role":TRANSLATOR_ROLE_ID}]}}'
   curl -s -X POST http://localhost:1337/api/copies -H "Authorization: Bearer $JWT" -H 'Content-Type: application/json' -d '{"data":{"publication":BOOK_ID,"copyNumber":1}}'
   ```

5. JavaFX: σύνδεση με τον ίδιο librarian.

## Σύνδεση και αποσύνδεση
- [ ] Αν το JavaFX είχε αποθηκευμένη συνεδρία από παλιά βάση: στην εκκίνηση (με τη Strapi σε λειτουργία) εμφανίζεται η οθόνη σύνδεσης.
- [ ] Μετά τη σύνδεση η ένδειξη δείχνει «● Online». Κλείστε και ξανανοίξτε την εφαρμογή: παραμένει συνδεδεμένη και «● Online».
- [ ] Με τη Strapi σταματημένη, η εφαρμογή ανοίγει χωρίς νέα σύνδεση και δείχνει «● Offline».
- [ ] «Αποσύνδεση» (κάτω αριστερά) → επιβεβαίωση → οθόνη σύνδεσης. Νέα σύνδεση → Πίνακας Ελέγχου, και οι συντομεύσεις (π.χ. F5) λειτουργούν μία φορά, όχι διπλά.

## Έντυπα
- [ ] Η λίστα δείχνει την «Αυτοοργάνωση». Στη στήλη Συγγραφέας εμφανίζεται μόνο «Νίκη Λοϊζίδη», όχι ο μεταφραστής.
- [ ] Δεν υπάρχουν κουμπιά Προσθήκη / Διαγραφή / Αντίτυπα. Υπάρχει «Προβολή», ενεργό μόνο με επιλογή.
- [ ] Τα Ctrl+N και Delete δεν κάνουν τίποτα.
- [ ] Το «Προβολή» και το διπλό κλικ ανοίγουν το παράθυρο «Έντυπο».

## Παράθυρο «Έντυπο»
- [ ] Τίτλος, Τύπος «Μπροσούρα», Εκδότης, Έτος 2019. Κενά πεδία δεν εμφανίζονται.
- [ ] Προέλευση: «Τοπική εγγραφή — εκκρεμεί έλεγχος από τον καταλογογράφο».
- [ ] Συντελεστές: «Νίκη Λοϊζίδη — Συγγραφέας», «Παναγιώτης Σκόνδρας — Μεταφραστής», με αυτή τη σειρά.
- [ ] Θέματα «—», Περίληψη «Δοκιμαστική περίληψη.».
- [ ] Αντίτυπα: φαίνεται το #1. Προσθήκη #2, αλλαγή κατάστασης σε GOOD, όλα γίνονται χωρίς σφάλμα.
- [ ] Δανείστε το #1 από «Δανεισμοί». Ξανανοίξτε το «Έντυπο»: με επιλεγμένο το #1 η «Διαγραφή» είναι ανενεργή.
- [ ] Διαγράψτε το #2, επιστρέψτε το #1, διαγράψτε το #1, κλείστε: η «Αυτοοργάνωση» εξαφανίζεται από τη λίστα. Ξαναπροσθέστε αντίτυπο με curl για τα επόμενα βήματα.
- [ ] Σταματήστε τη Strapi και πατήστε «Ανανέωση» στα αντίτυπα → μήνυμα «Δεν υπάρχει σύνδεση με τον server.». Ξαναξεκινήστε τη Strapi.
- [ ] (Αν υπάρχει βιβλίο από Biblionet με εξώφυλλο) Το εξώφυλλο εμφανίζεται. Αν όχι, δεν εμφανίζεται μήνυμα λάθους.

## Συγγραφείς
- [ ] Η λίστα δείχνει **μόνο** «Νίκη Λοϊζίδη», όχι τον μεταφραστή. Έτη «1950–», Βιβλία στη βιβλιοθήκη 1.
- [ ] Αναζήτηση «ΛΟΪΖΊΔΗ» → τη βρίσκει. Αναζήτηση «λ» (1 χαρακτήρας) → όλη η λίστα. Αναζήτηση «ξξξ» → κενή.
- [ ] Δεν υπάρχουν Προσθήκη/Διαγραφή. Το «Έργα» και το διπλό κλικ δείχνουν την «Αυτοοργάνωση».
- [ ] Διπλό κλικ στην «Αυτοοργάνωση» μέσα στο «Έργα» → ανοίγει το «Έντυπο».

- [ ] Σταματήστε τη Strapi και ανοίξτε «Συγγραφείς»: ο πίνακας γράφει «Δεν υπάρχει σύνδεση με τον server.» (όχι απλώς «κενό»). Ξαναξεκινήστε τη Strapi.
- [ ] Συνδεθείτε με librarian **χωρίς** βιβλιοθήκη και ανοίξτε «Συγγραφείς»: ο πίνακας γράφει «Η ενέργεια δεν επιτρέπεται για τον λογαριασμό σας.».

## Εκδότες

- [ ] Το «Έντυπα» δείχνει την «Αυτοοργάνωση» με Συγγραφέα «Νίκη Λοϊζίδη».

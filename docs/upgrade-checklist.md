# Λίστα ελέγχου: αναβάθμιση σε Java 25, JavaFX 25, Spring Boot 4.1

Προετοιμασία: η Strapi τρέχει (`cd library-strapi && nvm use && npm run develop`). Στο IntelliJ, SDK του project: 25. Η τοπική βάση ξεκινά νέα (η παλιά φυλάχτηκε στο `data/backup-h2-old/`): μέλη και δανεισμοί από την αρχή.

## Εκκίνηση
- [ ] `./mvnw javafx:run` ξεκινά χωρίς σφάλμα και χωρίς προειδοποιήσεις «restricted method» της εφαρμογής (όσες αναφέρουν `jansi` ή `guava` είναι του ίδιου του Maven).
- [ ] `java -jar target/librarymanagementsystemdesktop-0.0.1-SNAPSHOT.jar` ξεκινά επίσης κανονικά (μετά από `./mvnw package -DskipTests`).
- [ ] Σύνδεση με τον Librarian.

## Εμφάνιση
- [ ] Τα εικονίδια του sidebar φαίνονται σωστά.
- [ ] Αλλαγή γλώσσας: όλα τα κουμπιά του sidebar, και η «Αποσύνδεση», αλλάζουν.
- [ ] Οι λίστες (έντυπα, μπροσούρες, περιοδικά, συγγραφείς, εκδότες, χρήστες) φαίνονται όπως πριν.

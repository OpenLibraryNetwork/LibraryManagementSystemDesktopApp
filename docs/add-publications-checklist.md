# Λίστα ελέγχου: Προσθήκη βιβλίων και μπροσουρών (υπο-έργο 2β)

Προετοιμασία: Strapi σε λειτουργία (Node 20), librarian με βιβλιοθήκη, σύνδεση στο JavaFX.
Σενάρια με **[Biblionet]** κάνουν πραγματικές κλήσεις στη Biblionet (καταναλώνουν ημερήσιο όριο).

## Οθόνες
- [ ] Στο sidebar υπάρχουν «Βιβλία» και «Μπροσούρες» ως ξεχωριστά κουμπιά.
- [ ] «Βιβλία»: μόνο βιβλία, με στήλη ISBN, κουμπιά «Προσθήκη Βιβλίου» και «Προβολή».
- [ ] «Μπροσούρες»: μόνο μπροσούρες, χωρίς στήλη ISBN, κουμπιά «Προσθήκη μπροσούρας» και «Προβολή».
- [ ] «Προβολή» σε οποιαδήποτε από τις δύο → το ίδιο παράθυρο «Έντυπο» (στοιχεία + αντίτυπα).

## Προσθήκη βιβλίου
- [ ] ISBN «123» → μήνυμα «Μη έγκυρο ISBN…» κάτω από το πεδίο, χωρίς αλλαγή σελίδας.
- [ ] **[Biblionet]** Ελληνικό ISBN που υπάρχει στη Biblionet → προεπισκόπηση με συντελεστές («Όνομα — Ρόλος»), εκδότη, θέματα· «Βρέθηκε στη Biblionet…» → Επόμενο → 2 αντίτυπα NEW → Ολοκλήρωση → το βιβλίο εμφανίζεται στη λίστα με 2/2.
- [ ] Το ίδιο ISBN ξανά → «Υπάρχει ήδη στη βιβλιοθήκη σας (2 αντίτυπα)» και κουμπί «Προσθήκη επιπλέον αντιτύπων» → 1 αντίτυπο → στο «Έντυπο» τα αντίτυπα είναι #1, #2, #3.
- [ ] **[Biblionet]** ISBN που δεν υπάρχει στη Biblionet (π.χ. ξένο 979…) → φόρμα με κλειδωμένο ISBN και μήνυμα «…θα ελεγχθεί από τον καταλογογράφο».
- [ ] Στη φόρμα: Επόμενο με κενό τίτλο → «Ο τίτλος είναι υποχρεωτικός.»· έτος «πέρσι» → «Το έτος πρέπει να είναι αριθμός.».
- [ ] Κυλήστε τη φόρμα στο τέλος και πατήστε Επόμενο με κενό τίτλο → η φόρμα επιστρέφει στην αρχή, όπου φαίνεται το μήνυμα.
- [ ] Συμπληρώστε τίτλο, συγγραφέα (αναζήτηση), εκδότη, θέμα → Επόμενο → Ολοκλήρωση → εμφανίζεται στη λίστα· στο «Έντυπο»: «Τοπική εγγραφή — εκκρεμεί έλεγχος από τον καταλογογράφο».
- [ ] Ακύρωση σε οποιοδήποτε βήμα → δεν δημιουργείται έντυπο (η λίστα δεν αλλάζει).
- [ ] Φόρμα για ISBN που δεν βρέθηκε, συμπληρώστε τίτλο και συγγραφέα → Πίσω → **άλλο** ανύπαρκτο ISBN → η φόρμα είναι άδεια. Πίσω → **ίδιο** ISBN → τα στοιχεία είναι ακόμη εκεί.
- [ ] Αντίτυπα: σβήστε τον αριθμό ή γράψτε 0/60 και πατήστε Ολοκλήρωση → μήνυμα «…από 1 έως 50» (γράμματα δεν πληκτρολογούνται).

## Προσθήκη μπροσούρας
- [ ] Πριν από αναζήτηση το «Δεν βρέθηκε — Νέα μπροσούρα» είναι ανενεργό· ενεργοποιείται μετά την αναζήτηση και ξαναγίνεται ανενεργό αν αλλάξει το κείμενο.
- [ ] Αναζήτηση «Ν.» → «Πληκτρολογήστε τουλάχιστον 2 χαρακτήρες.» (δεν γίνεται κλήση).
- [ ] Αναζήτηση υπάρχουσας μπροσούρας (π.χ. από τη λίστα ελέγχου του 2α) → εμφανίζεται με «Στη βιβλιοθήκη σας: Ν αντίτυπα»· Επιλογή → προεπισκόπηση → αντίτυπα → Ολοκλήρωση.
- [ ] Αναζήτηση ανύπαρκτου τίτλου → «Δεν βρέθηκε…» → «Δεν βρέθηκε — Νέα μπροσούρα» → ο τίτλος είναι προσυμπληρωμένος.
- [ ] Αλλάξτε τον τίτλο στη φόρμα → Πίσω → ξανά «Νέα μπροσούρα» με την ίδια αναζήτηση → ο τίτλος σας δεν αντικαθίσταται. Με άλλη αναζήτηση → νέα, άδεια φόρμα.
- [ ] Νέα μπροσούρα με ίδιο τίτλο, εκδότη και έτος με υπάρχουσα → μετά την Ολοκλήρωση επιστρέφει στη φόρμα με «Υπάρχει ήδη μπροσούρα…» (ορατό στην αρχή της φόρμας, ακόμη κι αν ήταν κυλισμένη) και «Χρήση αυτού» → προεπισκόπηση της υπάρχουσας → αντίτυπα → Ολοκλήρωση.

## Συντελεστές, εκδότης, θέματα
- [ ] Αναζήτηση προσώπου «ΛΟΪΖΊΔΗ» βρίσκει τη «Λοϊζίδη»· γρήγορη πληκτρολόγηση δεν αφήνει παλιά αποτελέσματα.
- [ ] Κλικ σε όνομα από τις προτάσεις → μπαίνει **αμέσως** στη λίστα συντελεστών με τον ρόλο που φαίνεται δίπλα («Συγγραφέας» ως προεπιλογή) και η αναζήτηση καθαρίζει. Τα βελάκια μόνο μετακινούν· το Enter προσθέτει.
- [ ] Αποθήκευση με συντελεστή → στο «Έντυπο» φαίνεται ο συντελεστής (το σφάλμα όπου ο επιλεγμένος συγγραφέας χανόταν).
- [ ] Ίδιο πρόσωπο με ίδιο ρόλο → «Ο συντελεστής υπάρχει ήδη…»· αλλαγή ρόλου και ξανά κλικ → επιτρέπεται.
- [ ] «Νέο πρόσωπο» (ή «Χρήση αυτού» στο διπλότυπο) → το πρόσωπο μπαίνει αμέσως στη λίστα συντελεστών.
- [ ] ▲▼ αλλάζουν σειρά, ✕ αφαιρεί· η σειρά φαίνεται ίδια στο «Έντυπο» μετά την αποθήκευση.
- [ ] «Νέο πρόσωπο» με όνομα που υπάρχει → «Υπάρχει ήδη πρόσωπο…» με λίστα και υπόδειξη προσδιορισμού· «Χρήση αυτού» → επιλέγεται το υπάρχον.
- [ ] «Νέο πρόσωπο» με ίδιο όνομα **και** προσδιορισμό «1950-» → δημιουργείται.
- [ ] «Νέο πρόσωπο» και μετά Ακύρωση όλου του οδηγού → δεν δημιουργείται έντυπο· το πρόσωπο υπάρχει (το βλέπει ο καταλογογράφος στο admin με `reviewed = false`).
- [ ] Εκδότης: κλικ (ή Enter) σε πρόταση → επιλέγεται και η αναζήτηση καθαρίζει· τα βελάκια μόνο μετακινούν. «Νέος εκδότης», «Καθαρισμός» → χωρίς εκδότη.
- [ ] Θέματα: φίλτρο «πεζο» χωρίς τόνους· επιλογή με checkbox· «Επιλεγμένα θέματα: Ν».

## Σφάλματα
- [ ] Σταματήστε τη Strapi και πατήστε «Αναζήτηση» (ISBN ή μπροσούρα) → «Δεν υπάρχει σύνδεση με τον server.», ο οδηγός μένει ανοιχτός.
- [ ] Σταματήστε τη Strapi στο βήμα «Αντίτυπα» και πατήστε Ολοκλήρωση → μήνυμα κάτω από τα αντίτυπα· ξεκινήστε τη Strapi και ξαναπατήστε → ολοκληρώνεται.
- [ ] Μερική αποτυχία αντιτύπων (π.χ. Strapi σταματά στη μέση) → «Δημιουργήθηκαν X από Y», πλήθος και κατάσταση κλειδώνουν, «Δοκιμή ξανά» φτιάχνει μόνο τα υπόλοιπα, με συνεχόμενους αριθμούς.
- [ ] Διπλό γρήγορο πάτημα «Ολοκλήρωση» → μία μόνο προσθήκη (το κουμπί απενεργοποιείται).
- [ ] Όσο τρέχει η «Ολοκλήρωση», το «Ακύρωση» είναι απενεργοποιημένο και το κλείσιμο του παραθύρου (✕) δεν έχει αποτέλεσμα.

## Λίστες και dashboard
- [ ] Κάτω από κάθε λίστα (Βιβλία, Μπροσούρες, Περιοδικά, Συγγραφείς, Εκδότες) το «Σύνολο: N στοιχεία» δείχνει αριθμό, όχι «{0}».
- [ ] Εκδότες: στήλες Τηλέφωνο, Email, Ιστότοπος (όπου υπάρχουν από τη Biblionet).
- [ ] Dashboard «Πιο δημοφιλή»: μικρογραφία εξωφύλλου για όσα έχουν· δύο βιβλία με ίδιο τίτλο μετρώνται χωριστά.
